# EBS partnership assets

## Logo
- Partner logos on the site are fetched from **CMS** (`Partner.logo` → `/cms-media/...`).
- `logo-wordmark.png` is a **fallback only** when CMS has no EBS upload (`EBS_LOGO_FALLBACK_SRC`).

## Photos
Photos under `/partners/ebs/` are sourced from the public EBS Paris website
(https://www.ebs-paris.fr/) for UNM × EBS partnership communication.
Replace with assets provided by EBS / UNM communications when available.

Featured program covers (`featured-*.jpg`) sourced from ebs-paris.fr public media
for UNM × EBS homepage programme cards. Prefer official assets for production.
